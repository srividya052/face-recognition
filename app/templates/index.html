Ablation Study: MTCNN Alignment Fix

Comparison of face selection heuristic when multiple people appear in frame.

Variant Selection Method Accuracy AUC TAR@FAR=1%
v1 Baseline Largest face (MTCNN default) 97.18% 0.9790 95.23%
v2 Proposed Centered Face Weighting 99.30% 0.9994 99.43%

Key Finding:

Default MTCNN picks the largest face, which can be a bystander in photos with several people. Selecting the face with center_weighted_size raised 10-fold accuracy by +2.12 points (97.18% → 99.30%).

Reproduce via Terminal:

# Run full 10-fold LFW benchmark:
python -m src.evaluate --folds 10

# Fine-tune model with Contrastive Loss:
python -m src.train --epochs 5 --lr 1e-5
